## 프로젝트 소개

항공사 고객 만족도 설문조사 데이터를 분석하여 3가지 가설을 수립하고, 딥러닝 이진 분류 모델을 구축했다. 단순 예측 모델 개발에 그치지 않고, 카이제곱 검정과 상관관계 분석을 통해 만족도에 영향을 미치는 핵심 변수를 통계적으로 검증한 뒤 비즈니스 개선 방향을 도출했다.

---

## 가설 (Hypotheses)

| 가설 | 내용 |
|------|------|
| Hypothesis 1 | 비즈니스 목적일 경우 충성고객일 확률이 더 높다 |
| Hypothesis 2 | 비즈니스석을 이용할 경우 충성고객일 확률이 더 높다 |
| Hypothesis 3 | 충성고객일 경우 만족도가 높을 확률이 더 높다 |

→ 3가지 가설 모두 카이제곱 검정(p-value ≈ 0)으로 통계적 유의성 확인

---

## 내가 기여한 부분

- **단변량 분석**: Customer Type, Type of Travel, Class, Satisfaction 분포 파악
- **이변량 분석**: 카이제곱 검정으로 변수 간 관계의 통계적 유의성 검증
  - Business Travel / Disloyal Customer: χ² = 845.7
  - Satisfied / Disloyal Customer: χ² = 1667.4
  - Class / Satisfaction: χ² = 2836.9
- 분석 결과를 바탕으로 **두 방향의 비즈니스 개선안** 도출
- 발표 자료 제작 참여 및 **발표자** 역할 수행

---

## 핵심 인사이트

> 타 팀이 각 변수의 예측 기여도에 집중할 때, 우리 팀은 **비즈니스 관점의 거시적 해석**에 주안점을 뒀다.

카이제곱 검정과 모자이크 플롯 분석을 통해 도출한 결론:

- **Business Travel + Business Class + Loyal Customer** → 만족도 높음
- **Personal Travel + Economy Class + Disloyal Customer** → 불만족도 높음

이를 통해 해당 항공사가 **비즈니스 목적 충성 고객 중심의 수익 구조**를 가지고 있음을 파악하고, 개선 방향을 이원화하여 제시했다.

## 모델 성과

### 사용 피처
- Customer Type, Class, Type of Travel, Age (4개 변수)

### 머신러닝 (로지스틱 회귀)

| 지표 | Class 0 (불만족) | Class 1 (만족) | 전체 |
|------|-----------------|---------------|------|
| Precision | 0.83 | 0.76 | - |
| Recall | 0.79 | 0.81 | - |
| F1-score | 0.81 | 0.79 | - |
| Accuracy | - | - | **0.80** |

### 딥러닝 모델 구조

**Base Model**
```
Input(n_features)
→ Dense(64, relu) → Dropout(0.2)
→ Dense(32, relu) → Dropout(0.2)
→ Dense(1, sigmoid)
```
- optimizer: Adam(lr=0.001)
- loss: binary_crossentropy
- epochs: 100, batch_size: 32, validation_split: 0.2
- EarlyStopping(patience=10, restore_best_weights=True)

**Fine-tuning Model** (추가 데이터 유입 후)
```
Base Model (가중치 동결 유지)
→ 마지막 레이어 교체
→ Dense(4, relu) → Dropout(0.5)
→ Dense(1, sigmoid)
```
- optimizer: Adam(lr=0.0001) — Base Model 대비 1/10로 낮춰 기존 가중치 보존
- epochs: 30, validation_split: 0.2

### 성능 비교

| 구분 | Accuracy | 불만족(class 0) Precision | 불만족(class 0) Recall |
|------|----------|--------------------------|------------------------|
| Base Model (초기 데이터) | 97% | 0.90 | 0.81 |
| 추가 데이터 적용 후 | 89% ↓ | - | - |
| Fine-tuning 후 | **95%** ↑ | **0.95** | **0.96** |

- 추가 데이터 유입 시 성능 하락 확인 → Fine-tuning으로 회복 및 향상
- 출력층 교체 + lr 축소로 기존 학습 지식을 보존하면서 새 데이터에 적응
- **모델의 실환경 적응력 검증**이 핵심 성과

## 비즈니스 개선안

상관관계 히트맵 분석을 통해 만족도와 연관성 높은 서비스 항목을 특정하고 개선 방향 도출:

| 방향 | 개선 전략 | 근거 |
|------|-----------|------|
| **만족도 극대화** | 충성고객이 만족하던 서비스 유지·강화 | 충성고객 만족 패턴 분석 |
| **불만족 최소화** | 비충성고객의 불만 항목 집중 개선 | 불만족 고객군 분포 분석 |

**4가지 구체 개선안:**
1. 예약·보딩·와이파이를 하나로 묶은 **스마트 디지털 서비스 통합**
2. 청결과 좌석 편안함을 동시에 잡는 **안심 쾌적 기내 환경 조성**
3. 고객 취향을 반영한 **맞춤형 콘텐츠 및 엔터테인먼트 경험 강화**
4. 수하물부터 기내 서비스까지 **운영 프로세스 신뢰 확보**

## 문제 해결 경험

**협업 중 데이터 해석 방향 충돌**
- 상황: 편향 데이터를 균등 분석할지, 집중 분석할지 팀 내 의견 분기
- 해결: 편향 항목에 카이제곱 검정 직접 적용 → 불만족도와의 통계적 유의성 확인으로 방향 합의

**6시간 내 전 과정 수행이라는 시간 제약**
- 선택과 집중: 거시 분석·모델·방향성 우선 달성
- 미시 분석 및 세부 실행안은 미완 → 다음 프로젝트 보완 과제로 명확히 인식
