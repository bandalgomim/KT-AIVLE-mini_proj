# 🎓 강사와 수강자 두 주체를 고려한 교육용 AI Agent

## 개요

| 항목 | 내용 |
|------|------|
| **기간** | 2026.04.27 ~ 2026.04.28 |
| **목표** | PPT 업로드만으로 강의 영상·퀴즈·설문을 자동 생성하고, 결과를 강사에게 피드백하는 AI 에이전트 구축 |
| **역할** | 기획 아이디어 제안 · 발표 자료 제작 총괄 · 발표 |
| **기술 스택** | Python · LangChain · LangGraph · OpenAI GPT · TTS(OpenAI) · SQLite · Gradio · Tavily Search |
| **산출물** | PPT → 강의 영상 자동 생성 AI 에이전트 (퀴즈 + 설문 + 피드백 루프 포함) |

---

## 프로젝트 소개

PPT 파일을 업로드하면 AI가 슬라이드를 분석하여 강의 스크립트를 생성하고, TTS와 영상으로 변환한다. 수강자는 퀴즈와 설문을 통해 학습 성취도를 확인하고, 그 결과는 DB에 저장되어 다음 강의 스크립트 생성에 자동으로 반영된다. 강사와 수강자 두 주체 모두를 고려한 피드백 루프가 핵심이다.

---

## 시스템 아키텍처 (LangGraph)

| 노드 | 역할 |
|------|------|
| `parse_all` | 전체 슬라이드 파싱 (텍스트 / 표 / 이미지 / 스냅샷) |
| `gen_page` | 멀티모달 입력으로 슬라이드 내용 분석 |
| `search` | 슬라이드 내용 기반 외부 자료 검색 (Tavily) |
| `tool_node` | 툴 호출 실행 — search와 조건부 엣지로 연결 |
| `extract_result` | 검색 결과 추출 및 page_content 저장 |
| `script_assistant` | SQLite DB에서 이전 피드백 조회 → LLM 요약 |
| `gen_script_ctx` | 피드백 요약 + 페르소나 + 말투 반영 → 스크립트 생성 |
| `generate_quiz` | 스크립트 기반 객관식 퀴즈 생성 (Pydantic 구조화 출력) |
| `tts` | OpenAI TTS로 음성 생성 (4종 페르소나) |
| `generate_video` | 슬라이드 이미지 + 음성 → 영상 합성 |
| `acc_step` | 슬라이드 누적 — 미완료 시 `gen_page`로 복귀 (루프) |
| `concat` | 전체 슬라이드 영상 병합 → 최종 강의 영상 출력 |

**흐름 요약:**
- `search → tool_node`: 조건부 엣지 (툴 호출 필요 시에만 분기)
- `acc_step → gen_page`: 슬라이드 수만큼 반복 (continue)
- `acc_step → concat`: 전체 완료 시 종료

## 내가 기여한 부분

### 기획
- **"강사"라는 주체를 발견** — 기존 아이디어가 수강자 중심으로 편중되어 있을 때, PPT를 제공하는 강사도 핵심 사용자임을 제안하여 프로젝트 방향을 이원화
- 이로 인해 단방향 콘텐츠 생성 도구에서 **강사-수강자 피드백 루프 시스템**으로 기획이 확장됨

### 발표

- 코드 구조를 파악하여 기술적 내용을 비개발자도 이해할 수 있는 형태로 설명

## 핵심 기능 상세

### 1. 슬라이드 분석 (멀티모달)
- `node_generate_text`: 텍스트 + 표 + 이미지(최대 3장)를 멀티모달로 GPT에 전달
- Tavily Search 연동으로 슬라이드 내용 외 추가 자료 검색 가능

### 2. 피드백 루프 (핵심 차별점)
- `node_summarize_feedback`: SQLite에서 이전 수강생 피드백 + 슬라이드별 평균 난이도 조회
- LLM이 피드백을 2~3문장으로 요약 → 다음 스크립트 생성에 자동 반영
- DB 스키마: `lectures` (강의 메타) ↔ `survey_responses` (슬라이드별 난이도 + 피드백)

### 3. 스크립트 생성
- `node_generate_script`: 페르소나(4종) · 말투 · 청중 수준(전공자/비전공자) · 이전 피드백 요약을 모두 반영
- 슬라이드당 60~90초 분량, 이전 슬라이드 마지막 100자를 컨텍스트로 연결

### 4. 퀴즈 생성 (구조화 출력)
- `node_generate_quiz`: Pydantic + LCEL 체인으로 구조화된 퀴즈 출력
- 청중 수준(level)에 따라 난이도 자동 조절
- 출력 형식: 질문 · 4지선다 · 정답 번호 · 해설

### 5. TTS 음성 생성
- OpenAI TTS API 사용, 페르소나별 instruction 프롬프트로 말투 제어
- 4종 음성 지원: 친절한 AI 강사 / 10년차 현업 전문가 / 대학교수 / 친한 선배
